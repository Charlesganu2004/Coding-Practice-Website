Honest by design

Practice locally. Ask for help when you choose.

Write C++20 or Python 3.12 in the editor, use the supplied test ideas locally, and get transparent offline coaching. You can optionally connect your own local AI server for hints and draft feedback; no cloud key is shipped with this site. GitHub Pages cannot securely hide tests or safely run arbitrary C++/Python, so nothing here claims to be a secure code runner.
